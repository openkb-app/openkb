# Security

Please do not report vulnerabilities in public issues.

- **Backend** (`openkb/`, `web/modules/`): the Drupal security team's process — see [Drupal security](https://www.drupal.org/security) and the project page at [drupal.org/project/openkb](https://www.drupal.org/project/openkb).
- **Frontend, images and everything else in this repository**: [GitHub private vulnerability reporting](https://github.com/openkb-app/openkb/security/advisories/new).

Supported: the latest minor release. Fixes ship as a patch release of both images.
